- 总部填写审核说明，独立审核或退回当前页选中的差异补证。前端按当前角色/权限/区域显示入口，实际授权、版本和同一人员不能自审仍由后端决定；原左右数量不变。

- 页面全局展示这个浏览器内尚待核验的原请求，刷新或重新进入后可查询。其他人员的记录不能被覆盖或清除。永久终结必须勾选明确确认；已提交的业务仍返回原回执。

## 持久恢复约束

`dailyReviewRecoveryStore.ts` 用 Web Locks 按截止对象协调标签页。发送前先把安全坐标持久化并回读；存储、锁、记录校验失败时停止发送。记录只含版本、种类、截止 ID、原人员/授权版本、原审核版本、操作和原请求号；正文、业务幂等键、令牌、摘要和签名 URL 均不写入浏览器存储。

提交、原结果查询与终结均使用 `apiNoReplay`。收到业务回执后仍须单独按原坐标取得匹配的服务端证明，并复查当前身份，才可清除记录。超时、401/403/409/503、丢失结果、前后身份变化、回执不匹配、对象切换和组件退出保留原记录；`not_observed` 不授权重试。

恢复保留原授权版本，同时传当前授权版本；当前有效身份可恢复自己的历史请求。清理必须持有对象锁、匹配精确记录，且只接受 `found` 或 `sealed`。换人、原请求未终结、损坏记录和存储故障均不能另起请求覆盖它。
