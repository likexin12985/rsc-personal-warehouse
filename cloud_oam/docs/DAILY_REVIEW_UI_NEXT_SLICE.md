## 已实现的边界

- 私有 `/xx/daily-reconciliations` 显示当前可见区域，列表/明细/历史按当前版本读取。当前页面内存保留草稿与已完成附件；身份变化清理正文。
- 提交前在对象 Web Lock 内写入并回读安全坐标；新提交不得覆盖未核验、损坏或其他人员的记录。刷新后只凭安全坐标查询原请求，不保存正文、令牌、签名 URL 或幂等键。
- `apiNoReplay` 防止认证刷新后的自动重放；`not_observed` 不释放记录。只有准确匹配的原回执或永久终结证明、当前身份复查和精确记录清理全部成功，才解除该原请求。
- 区域可按本页所选差异分批解释；附件必须先完成 `daily_reconciliation_evidence` 上传。总部可独立审核或退回指定项，数据库继续拒绝同一人员自审和旧版本写入。
- 证据通过私有短期地址打开，不把应用认证头或 referrer 发给对象存储；公开首页和小程序仍仅知识查询，星星指向 `https://rscwz.cn/xx`。
