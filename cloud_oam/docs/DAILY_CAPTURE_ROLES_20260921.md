## 剩余上线依赖

1. **新增角色后的备份恢复**：逻辑备份引用两个新角色/策略；旧 B5 六角色恢复不覆盖当前八角色。
   需要独立新凭证、恢复前准备和恢复后验证/启用流程。当前 CLI 只接受 0130 完整结构和
   两个账号均不存在或均正确，不能拿“预建 NOLOGIN 账号”冒充已经支持恢复激活。
2. 日终任务进程/容器配置、区域查询、差异解释/审核、真实映射批准和连续三天对账尚未验收。
   新增采集账号不等于日终任务已经执行；对账解释或批准不产生库存变化。
3. 当前 CI 静态选择包含新角色检查；这些本地原生场景尚不能替代准确候选的完整 GitHub PG16/Client 门禁。
   当前整套静态尚未成功，旧 API 镜像不包含本批代码，需构建当前工件并重新验证。
4. 托管数据库受限管理员、真实网络/SCRAM 配置、真实 OSS、通知渠道和设备验收仍缺。

没有提交、推送或部署；没有真实来源读取、通知/短信发送或生产数据库操作。
