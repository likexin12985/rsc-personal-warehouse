## 问题与结果

0161 报损纠正封存守卫对包含操作者和请求编号的普通审计也锁定库存流水头。真实登录会话因此等待无关库存事务；授权发布持有人员锁时，可能与持有库存锁的期初任务互相等待，形成死锁。

0164 调整 `rsc_fence_loss_correction_seal_0161` 的审计范围：库存和需求审计继续执行库存锁及封存检查；其他业务域的普通审计独立提交。下列三种封存对象不享受审计域豁免，即使被错误标成 authentication 或 authorization 也仍受约束：

- `stock_loss_inverse_request_seal`
- `stock_loss_correction_approval_seal`
- `stock_loss_correction_execution_seal`

报损、逆向冲销、审批和库存过账的事实守卫、幂等绑定、历史保留、通知和恢复规则不变。认证会话本身的身份、频控、会话及审计保护仍由各自正式入口负责。
