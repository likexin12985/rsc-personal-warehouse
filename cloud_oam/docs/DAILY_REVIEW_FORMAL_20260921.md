## 实现和权限

- 新增不可变命令、绑定及事务消费三张表，保留通用对账运行/明细以及原截止档案。
  命令、投影、状态变化和审计必须在同一事务中完成；延迟循环外键阻止未消费命令提交。
- 发起权限授予总部和区域负责人；解释权限仅区域负责人；审核权限仅总部。
  提交时重新核验人员、会话、精确区域授权和附件；同一人员不能审核自己解释过的对账。
- API 只对三表拥有 SELECT/INSERT；绑定仅四列可更新。12 个函数中只有投影核验入口
  可由 API 调用，其余为私有函数；12 个 ALWAYS 触发器中 3 个在事务提交时检查。
  启动时同时校验函数正文、ACL、触发器与两条命令闭环外键的真实执行约束。
- 服务从数据库读取截止和历史，使用实际 JWT/会话。按会话、授权图、精确截止、文件和
  审计链顺序取锁；设置 5 秒锁等待与 15 秒单语句超时。完整 HTTP 请求期限及断线恢复入口
  留待下一批，单语句超时不能冒充完整请求期限。
- 空新模块允许回退；已有日终命令/审计/状态历史时拒绝回退。权限种子被修改、删除或
  分配给额外角色时也拒绝自动删除。旧期初守卫分支逐字节保留。
- SQLite 仅验证结构及空迁移往返；正式审核服务只接受 PostgreSQL API 角色。
