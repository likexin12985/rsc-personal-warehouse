真实 PG16 的正数过账后独立对账，触发 0026 私有函数的 `event_type` 变量与 outbox 列名
歧义，报 SQLSTATE `42702`。新增前向迁移 `20261106_0127`，准确重命名 12 处局部变量
引用为 `expected_reconciliation_event`，两个 `outbox.event_type` 列引用及全部业务比较
保持原义。前 126 个迁移文件未改，没有新增表、触发器、函数或运行角色权限。

迁移先核对固定正文、owner、私有 ACL、invoker 属性和两项 ALWAYS 触发器，再原位替换
正文并推进 readiness；保留函数 OID、所有权及权限。API 启动校验新增准确函数正文固定值，
没有授予 API 或 Edge 直接执行该函数的权限。源码、ACL、关闭触发器和新增别名触发器的
四种偏移均使迁移拒绝；注入的偏移只存在于临时库回滚事务中。
