## 本批实现

后台期初盘点准备选择区域后，可查看该区域的已发布控制批次。页面分别显示来源、采集时间、
发布时间、发布证据截止时间和控制明细条数，并区分最新发布与历史批次。历史和已过期记录
保留供查阅；无批次不代表零库存，零条明细也不代表个人仓库存已经完成建账。

新增 `GET /api/v1/stocktakes/opening/start-options/control-batches`，参数仅为区域、页大小及
游标。服务器从当前正式身份取得人员和授权版本，要求全国总部管理员或准确区域负责人、
`stocktake.manage` 权限及全局 deny 判定。返回前复核身份、授权时间边界、区域和批次摘要；
越权、数据库故障或读期间变化都不能伪装成空目录。响应禁止缓存，不生成业务键或写入事实。

新增前向迁移 `20261103_0124_opening_control_directory.py`：

- `star_oam_api` 仅新增执行一个固定签名、固定正文摘要的 `SECURITY DEFINER STABLE`
  JSON 函数的能力。函数自行核验身份、区域角色、权限和全局拒绝；只允许 READ COMMITTED。
- 只返回八个批次摘要字段，最多请求条数加一条私有翻页前瞻，不返回控制数量、SyncRun、
  原始 payload、来源明细、文件地址或发布者会话。API、Edge、projector 对四张发布私表仍无 SELECT。
- PostgreSQL 增加区域/ID 非唯一索引，支持按区域的有限游标读取；无新表、触发器或业务事实。
- migration owner 必须是直接登录身份。downgrade 在移除函数/索引前核验正文、属性、准确 ACL
  及索引定义；所有变化与 readiness 同事务，失败回滚。此前 123 个迁移不改写。

网页按人员、授权版本和区域隔离响应。切换区域、刷新区域或读取失败立即丢弃旧批次选择；
晚返回的旧请求不能覆盖新区域。读取使用 `apiNoReplay`，不触发认证重放或保存启动命令。
公开首页、小程序知识查询及星星后台 `/xx/` 入口不变。
