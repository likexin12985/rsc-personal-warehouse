3. 历史来源使用创建事件、范围 key/hash/manifest 和截止快照；不要求无关旧执行人今天仍在职。
   当前 caller、授权版本、目标范围及保管关系仍按当前数据库时间校验，文件等待后和返回前重验。
4. released 冻结只在完整唯一的过账 completion、有效审批范围/轮次、释放时间/操作者/固定原因、
   approved→posted 事件与审计都能重证时成立；全部历史实盘必须早于或等于释放时点。
   复用的是纯有效审批证据算法，不伪装旧时间或任务状态，不调用要求当前恰为 posted 的重放入口。
   该证明仅确认历史计数发生在合法冻结区间，不对外提供库存过账/关闭完成回执。
