## 比较范围和时间

映射版本明确给出每个库位的区域、目标仓库及纳入的库存状态，并绑定本次库位和组织事实摘要。
全部库位都需明确映射，含无库存和未使用库位；新增、缺失或重复映射拒绝计算。不从库位名、
父级继承、资产所属组织或物料名称推断区域。非目标区域显式标记，不能暗中将未映射库存过滤掉。
当前测试映射是固定 UUID 的合成夹具，**没有真实批准事实**。

来源数量按已发布控制量比较；锁定量逐 origin 单独保留，不擅自相加或扣除。当前合成口径
包括 available、reserved，两者之间占用流转不增加总量；排除状态时保留排除数量及原因维度。
适配复核原始两侧摘要、来源仓库/库位覆盖、origin 数、账本表计数、交易/流水完整前缀，
调用原内核按仓库、物料 UUID、成色左右比较，结果保留全部原始摘要及映射摘要。

来源时间使用原始 `captured_at`，本地时间使用账本 MVCC 采集观察时间；来源重新读取时间
另外记录，不替换原时间。上海业务日期和 300 秒采集偏差约束仍由内核校验。历史读取可复算，
不会因此恢复当前来源权限。内容摘要也不会授予操作者、映射或生产 schema 权限。

## 实际 PG16 证据

使用新建的私有 Unix socket PG16 16.15 实例，恢复原合成应用备份后，经正式授权、签名
采集和发布函数新建两次来源发布。两个专用只读角色分别实际读取来源与账本，**没有重写
任一侧采集时间**。只有源查询和文件存储为合成传输；数据库守卫保持开启。

| 场景 | 核对结果 |
| --- | --- |
| 两仓四条来源 | W-A/new=5、W-B/new=7、W-B/damaged=4；本地两种已有物料各 1。物料 UUID 不同，保留 5 个比较明细，不强行匹配。两侧相差 1.768299 秒 |
| 两目标仓全空 | 来源 0 条但仓库覆盖和零页完整；本地两种物料各 1，生成两个 -1 差异。两侧相差 1.300710 秒 |
| 历史输入重放 | 后续空仓发布后，原两侧快照和映射重算，完整结果相同，不替换原截止游标 |

两个采集对的账本截止游标均为 3。实际检查把计算结果与独立 SQL 的余额投影和手工来源
预期相比较；离线复核器又从原始流水按有向数量独立求和。每对读取前后 **34 张表摘要一致**；
包括发布在内的整个流程中，六张库存事实表摘要一致。

纯测试另覆盖相同物料准确匹配、占用量保留、全部空来源、旧来源新读取、上海跨日、摘要
损坏、缺页、重复 origin、截断账本、空交易、新库位和资产组织/物理范围分离。
纯测试为独立构造的输入，部分时间经过明确调整；这些不计作实际 PG16 采集证据。
