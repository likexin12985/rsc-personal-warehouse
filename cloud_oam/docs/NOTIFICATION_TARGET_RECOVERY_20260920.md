后续 7.38 已[统一首次创建与恢复的身份解析](NOTIFICATION_CHANNEL_IDENTITIES_20260920.md)，下文保留本切片历史边界。

## 运维契约

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/notifications/person-targets` | 默认查询没有目标绑定的人员，可用 `unbound_only=false` 看全部；按创建时间和 UUID 使用 keyset 分页，单页最多 100 条 |
| `GET /api/v1/notifications/person-targets/legacy-events` | 单独列出历史 NULL 摘要事件及已有接收项数量；不推测或补写完整原目标 |
| `POST /api/v1/notifications/person-targets/{target_id}/recover` | 使用原观察摘要、所选已验证渠道、原因、独立幂等键和请求标识，显式恢复一条原本没有接收项的目标 |

读取要求有效的正式全国 admin 和 `notification_delivery.read`，恢复还要求 `retry`。
区域账号、受限交接、权限撤销、停用账号、伪造的服务调用上下文均不能执行恢复。
所有路由保持私有不缓存；列表和结果不返回手机号、openid、HMAC、凭据、provider 原响应或事件 payload。
调用者不能指定任意接收人、手机号、openid、provider 或身份 ID。

列表区分目标证据异常、已取消、已有接收项、人员/账号停用、缺账号、身份核验配置未就绪、
缺少已验证渠道和可恢复状态。默认列表只按“没有绑定”过滤，未绑定到目标的旧接收项也可能出现在
列表中，但会明确显示“已有接收项”并禁止恢复，不能绕过其已有投递记录。

## 身份与事务边界

- 按原 `person_id` 精确查询唯一账号，不能按姓名、组织或联系方式猜账号。
- 短信候选必须是当前账号规范手机号，且在配置的 PNVS 身份域、版本和 HMAC 密钥下，精确匹配
  已验证、未撤销的正式 `AuthIdentity`；微信只读取配置 app ID 下的唯一 `WechatIdentity`，
  再核对相同 app 身份域的正式 OpenID HMAC，不能取其他应用“最近登录”的身份。
- 身份需要产生当前有效正式人员权限，未来验证时间、失效账号/人员、缺失配置和不匹配摘要均关闭恢复。
  配置只用于核验身份域；本操作不构造发送 adapter，不读取发送凭据，不发起网络调用。
- 先观察账号绑定，按既有顺序取得操作者与目标账号的正式身份图锁，再取得目标事务 advisory lock
  和通知事件 `FOR UPDATE NOWAIT` 锁；加锁后重新核验当前操作者及目标映射。
  沿用的身份图锁包含共享角色目录行，不能据此宣称不同恢复操作已证明无互相等待。
- 观察摘要覆盖事件事实、payload 摘要、目标全集、人员/账号状态、已有接收项、最近恢复审计以及
  已验证身份的 ID、provider、版本、验证时间与内部 HMAC。即使身份 ID 不变，联系方式和对应 HMAC
  同时更新后也必须重新查询。HMAC 只参与内部观察摘要，不通过 API 或恢复审计输出原值。
- 恢复时追加 `NotificationRecipient` 和 `NotificationTargetBinding`，把原事件置回 `pending`，
  同事务追加 `notification_target.recovered` 到现有不可变审计链。调用者提交或回滚；审计失败时
  不得保留接收项、绑定或事件状态变化。之后由独立扩展创建 queued 投递，恢复接口不扩展或发送。
- 同一命令只回读原不可变结果，后来身份变化也不改写其历史结果。变化后的新命令需要最新观察摘要。
  被阻断的显式恢复也留审计；该审计会使旧观察版本失效。取消、已有接收项、失败或 unknown 投递
  均不通过换渠道建立另一条接收项规避原投递边界。

本切片只处理原目标原本没有任何接收项的情况。多个可用渠道中由操作者明确选择一个；不自动补齐
已有部分渠道的目标，也不声称原始通知渠道解析已经改造完成。

## 私有页面

`/xx/` 消息中心的全国通知运维区域新增“通知接收目标”，支持待解析、全部和历史目标未知三个范围。
只有可恢复状态且有权限的账号显示操作按钮。恢复请求使用 `apiNoReplay`，重复点击不会启动第二次写入。
超时、异常或无法核验的回复都要求先成功刷新当前目标；失败刷新、历史事件查询不能解除该要求。
成功回复仅表示原恢复审计，页面仍重新读取当前列表。权限变化会使未完成的旧请求结果失效，
正在写入时先发生的读取也不能解除未知结果限制。

公开知识首页、首页“星星后台管理”到 `/xx` 的入口和小程序页面注册规则没有改变。
