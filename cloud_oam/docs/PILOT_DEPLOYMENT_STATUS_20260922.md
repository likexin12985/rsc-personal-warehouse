## 当前 prepare/start 契约

新入口要求专属 `rsc-pilot-*` 项目、获审候选标签和工作树外的私有 state；两个阶段使用同一部署身份、state、候选文件、配置及烟测目标。prepare 用 UUID 内部标签构建 DB/API/Web，读取镜像 ID 后发布候选别名，复制静态只读挂载快照，完成独立卷上的迁移与 HEAD/容器/卷身份复核后，原子创建权限 0600 的成功回执；应用此时未启动。

start 必须先核对回执与源码、配置、镜像 ID、静态快照、DB 容器/卷及 HEAD。缺回执或不符则在 pin gate/API 变更前拒绝；所有实际启动使用已绑定镜像 ID。数据库 HEAD 通过绑定容器内的固定 Unix socket 只读查询，清除外部 libpq 覆盖、禁用 psql rc，并拒绝 conninfo 式数据库名。可选 `SMOKE_RESOLVE_HOST/IP` 须有效成对且在 prepare 前固定。

prepare 后仍须完成同一 registry、同一试点数据库的 KMS 双人计划复核和持久化 pin 登记。start 先执行 pin gate，再启动 API/Web、执行只读 HTTPS 冒烟。配置或输入变化需要新获审候选标签；不得删除旧回执、长期挂载快照或镜像来绕过拒绝。失败保留现场，不自动清理容器/卷、重建准备记录或迁移降级；CLI 停止也不等于 Docker 副作用已回滚。
