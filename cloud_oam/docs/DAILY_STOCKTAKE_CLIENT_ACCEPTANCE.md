## 本切片交付

- 两端日常盘点任务列表支持加载更多，第 51 项不再因固定第一页而无入口。
  Web 另提供已加载任务号筛选，并明确不代表全库搜索；刷新后可继续读取后续页。
- 服务端 `next_after_id` 是下一页首个未见 UUID，后续查询包含该 UUID；不是上页末项。
  页内及跨页重复、倒退、非递增游标、空页带游标、超过 50 项均失败关闭。
  若下一页首项已不再可见，允许返回更大的 UUID，不要求首项与游标相等。
- 列表读取前后复验身份/授权，刷新、切 adapter、隐藏、卸载使过期读取失效。
  写操作与加载更多互斥；旧写回调不能污染新页面、强制跳转或清理新请求的忙状态。
- Web 支持手工/扫码枪来源，以及 SKU、物料二维码、SN 文本、SN 二维码和不确定类型。
  小程序相机扫描使用 `unknown + scan`，手填使用 SKU/SN 文本和 `manual`。
  不在客户端解释标签内容或生成 material_id/serial_id；服务端原有精确解析与范围检查不变。
- 空 SN 对应 raw/type 双 null；带 SN 时本地先要求每行数量恰为 `1.000`。
  小程序扫码回调重验身份、权限、任务版本、轮次、范围和页面生命周期，手改标签撤销扫码来源。

审批、分配、占用、出库、发货、物流签收、OAM 收货、个人仓入库、通知送达和对账同步
仍独立。本切片不推进任何履约轴，不使期初启动准备变为 `start_ready=true`。

- 未运行微信真机相机/存储/前后台生命周期验收，Web 扫码枪也需真实设备验证。
- 未运行最终 Docker/Caddy 产物与 OSS、短信、微信登录联调。

- 页面生命周期防护不是跨进程持久化恢复（这是 `a78d5ad` 历史切片的边界）。当前
  `83f2223` 已为 Web 日常计数和两阶段复核接入独立 command-status GET 与持久哨兵；
  小程序及其他非计数动作仍需分别验收。已有期初 count 恢复接口仍限定 opening，不能直接挪用。
- 请求未知时不能因超时、刷新、`not_observed` 或换账号而认定未执行、清除屏障或换键重发。
  本切片保留现有未决意图，不声称解决所有历史未知写的恢复和人工封存。
