# 分配后库存占用页面验收记录

记录日期：2026-09-08。产品基线为仓库根目录的正式生产版需求与架构设计 V1.0。
本轮继续使用 `codex/production-readiness-gates`；备案办理与开发并行推进，备案结果
不代替功能验收、数据库门禁或生产发布验收。

## 本轮实现

- 正式需求详情新增独立库存占用面板，从真实分配事实选择来源、数量和 SN。
  候选来自 `GET /api/v1/material-requests/{id}/reservation-options?request_line_id=...`，
  返回分配余量、最新可用余额、投影坐标和精确 SN，不要求用户手工填写 UUID。
- 候选读取复用正式需求与库存权限，重读当前身份与显式拒绝规则，验证期初成立和流水投影。
  分配、历史占用或 SN 集合超过安全上限时停止返回，避免把截断结果当作完整库存。
- 写入与原命令恢复也独立重载需求对象权限，精确限定可见需求；拥有某个来源仓的库存权限
  不能授权处理不可见的外区需求。授权范围变化时保持失败关闭。
- 占用命令使用现有正式库存过账服务，将库存从可用账户转入相同维度的预置占用账户。
  原始余额版本、流水游标及 SN 集合写入命令结果。占用额度累计计入历史事实，不因后续状态
  改变而自动获得再次使用同一分配额度的权限。
- 网络结果不确定时保留持久恢复记录，通过原追踪坐标只读核验；不会自动重发写入。
  恢复核对原命令、占用事实、状态事件、完整审计链、库存移动与 SN 集合；当前余额或 SN
  位置变化不能替代原始命令证据。旧版或损坏的恢复记录保持阻断。
- 分配、占用和供给操作共享页面即时写入阻断。切换需求、身份、权限或卸载组件后，
  过期响应不能清除原恢复记录或提交新的写入。

## PG16 修复范围

`5a18a27` 修复 0069 源码替换条件中“新字符串已经包含在旧字符串内”的冲突，并补充
从 0059、0060、0061 历史函数体重建的正反向回归。后继修复同步 0069 修改的四个运行时
函数哈希及历史降级/再升级断言，保留 OID、owner、ACL 和目录往返一致性要求。

服务端不再对仅授予 SELECT/INSERT 的分配、占用事实表使用更新行锁；需求父对象锁继续
承担业务串行控制。没有扩大事实表的 UPDATE 权限。

工作流将真实 PG16 检查放在较长的静态套件之前，尽早反馈迁移与生产角色问题；
真库与静态两个步骤仍必须全部通过，未省略或降低原门禁。

## 验证与边界

本地测试覆盖普通数量与 SN、候选权限和范围、库存坐标漂移、审计/命令/移动证据篡改、
未知结果恢复、页面存储故障及并发写入阻断。真实 PG16 运行结果必须绑定准确提交 SHA；
本机按环境跳过的 PG16 测试不构成真库证据。远程结果以 GitHub Actions 的当前提交为准。

本轮本地占用服务与候选测试分别为 `35 passed`、`29 passed`，数据库安全和迁移相关回归为
`303 passed, 1 skipped`，关联需求/库存/API 回归为 `196 passed`；各组存在交集，不能
直接相加。Web 全量快照 `879 passed`，TypeScript 与生产构建通过，后续恢复边界修复
另有定向回归。Vite 保留主包体积提示，不影响构建结果。

真实 Chrome 合成数据检查覆盖普通候选、数量确认和 SN 勾选；已修复 SN 复选框与串码
文字错位，并隐藏候选页的内部流水游标展示。局部布局与文案调整不改变命令坐标或恢复
校验，面板 `20 passed`、类型检查通过。预览未连接真实接口，临时服务与文件已清理。

当前 runtime collector 尚未收集新增 0069 的两个 reservation guard 及其四个 trigger。
现有迁移静态测试与全库迁移/往返门禁不能代替这部分独立目录污染测试，也不能代替真实
PG16 上“分配 → 占用”完整服务链及并发 SN 的专门验收。

本轮未实现占用释放、拣货、出库、发货、物流签收、OAM 收货、个人仓入库、通知送达或
对账完成；这些状态保持独立。预生产迁移与恢复演练、真实身份及附件 UAT、外部依赖和
发布验收仍是上线前的独立工作。部署保护目录不纳入本轮提交。
