# 分配后库存占用页面验收记录

记录日期：2026-09-08。产品基线为仓库根目录的正式生产版需求与架构设计 V1.0。
本轮继续使用 `codex/production-readiness-gates`；备案办理与开发并行推进，备案结果
不代替功能验收、数据库门禁或生产发布验收。

## 本轮实现

- 正式需求详情新增独立库存占用面板，从真实分配事实选择来源、数量和 SN。
  候选来自 `GET /api/v1/material-requests/{id}/reservation-options?request_line_id=...`，
  返回分配余量、最新可用余额、投影坐标和精确 SN，不要求用户手工填写 UUID。
- 候选读取复用正式需求与库存权限，重读当前身份与显式拒绝规则，验证期初成立和流水投影。
  分配、历史占用或 SN 集合超过安全上限时停止返回，避免把截断结果当作完整库存。
- 写入与原命令恢复也独立重载需求对象权限，精确限定可见需求；拥有某个来源仓的库存权限
  不能授权处理不可见的外区需求。授权范围变化时保持失败关闭。
- 占用命令使用现有正式库存过账服务，将库存从可用账户转入相同维度的预置占用账户。
  原始余额版本、流水游标及 SN 集合写入命令结果。占用额度累计计入历史事实，不因后续状态
  改变而自动获得再次使用同一分配额度的权限。
- 网络结果不确定时保留持久恢复记录，通过原追踪坐标只读核验；不会自动重发写入。
  恢复核对原命令、占用事实、状态事件、完整审计链、库存移动与 SN 集合；当前余额或 SN
  位置变化不能替代原始命令证据。旧版或损坏的恢复记录保持阻断。
- 分配、占用和供给操作共享页面即时写入阻断。切换需求、身份、权限或卸载组件后，
  过期响应不能清除原恢复记录或提交新的写入。

## PG16 修复范围

`5a18a27` 修复 0069 源码替换条件中“新字符串已经包含在旧字符串内”的冲突，并补充
从 0059、0060、0061 历史函数体重建的正反向回归。后继修复同步 0069 修改的四个运行时
函数哈希及历史降级/再升级断言，保留 OID、owner、ACL 和目录往返一致性要求。

服务端不再对仅授予 SELECT/INSERT 的分配、占用事实表使用更新行锁；需求父对象锁继续
承担业务串行控制。没有扩大事实表的 UPDATE 权限。

分配服务同样通过既有数据库所有者锁函数锁定货源账户，分配事实读取不要求 UPDATE
权限。来源期初与投影证明限定到本次选定的账户，不再因无关仓库尚未建账而拒绝分配。
分配创建、幂等重放和历史恢复均重新验证需求对象可见范围及当前显式拒绝规则。
分配候选只校验当前物料的可用账户；同一查询内有仓库尚未建账时，只展示具有完整
期初证明的其他来源。没有任何成立来源时仍返回前置条件错误，不将未知库存显示为可用。

工作流将真实 PG16 检查放在较长的静态套件之前，尽早反馈迁移与生产角色问题；
真库与静态两个步骤仍必须全部通过，未省略或降低原门禁。

### 占用释放的原实施约束（接续状态见释放验收记录）

- 通过新的前向迁移增加 `stock_reservation_releases` 及其 SN 子表，绑定原占用、需求修订、
  操作前后版本、数量、原因、来源/目标账户、过账交易、操作者和幂等命令。原占用表的
  `released_qty` / `release_transaction_id` 不作为可以直接修改的余额或履约事实。
- 释放从原占用账户移回该占用记录的原可用账户。账户可能承载多笔占用，释放额度必须由
  本笔原占用减去已经释放/转出的事实计算；不能借用同账户另一笔占用的数量或 SN。
- 分配额度仍累计计算已占用、已释放和已转出数量，释放不自动产生再次占用同一额度的资格。
  需求聚合状态需要同时考虑历史占用、释放和转出，不能继续仅按原占用数量求和。
  新增占用、供给计划和历史命令恢复均需验证与 `partially_released` / `released` 的组合。
- 审批后取消是补偿流程；单独释放不等于需求取消，也不改变出库、发运、签收、收货、
  入库、通知或对账状态。后续取消命令必须关联补偿证据再独立完成。
- 创建、候选与恢复都要校验当前需求范围及来源/目标账户权限、显式拒绝和当前角色。
  新事实保留 SELECT/INSERT 边界；数据库保护函数、触发器、交易绑定及数量/SN 约束必须
  纳入启动检查。要验证原占用与释放直接 SQL 插入时不能复用同一库存交易或留下孤立事实。
- 核对释放与已有分配、占用、库存过账及盘点的锁序，避免新增相反锁序；更新流水、投影、
  释放事实、命令、状态事件、审计及 Outbox 必须在同一事务内。数据库失败不得留下部分释放。
- 页面使用有界的原占用候选，显示可释放数量和精确 SN；未知写入结果保留原追踪坐标，
  只读核验命令、反向库存流水及审计后再解除阻断，不自动补发 POST。
- 真库至少覆盖 `2.000 → 释放 0.500 → 释放 1.500`、同账户多笔占用、SN 子集、
  超额与重复释放、并发重放、授权撤销、过账后故障回滚、后续命令后的历史恢复及非空降级。
  新释放事实应在旧迁移各自的降级阻断已验证后创建，防止遮蔽历史门禁。
