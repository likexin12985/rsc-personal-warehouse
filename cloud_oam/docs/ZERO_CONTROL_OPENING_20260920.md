security definer、语言和固定 search_path，再按准确原文替换。函数 OID、ACL 和属性保持。
readiness 推进至 0122；没有新表、新触发器或运行角色权限。

这是锁定前置条件的修复，不是控制批次的新鲜度授权或公开选择接口。既有期初任务仍由
正式启动服务封存 scopes、cutoff、manifest、初轮、冻结、审计和任务启动 outbox。
控制为零不等于盘点完成，也不产生库存交易、余额或期初建账事实。
