启动/实盘服务。当前运行时要求正式发布及授权版本，使历史 schema 无法构造该样本。
本批改为独立的冻结合成数据，执行语句只包含 0051 的列，测试不再导入当前业务服务。
没有为生产运行时增加缺字段、缺函数或缺发布证明时的放行路径。

集群运行归档提交 `7556de2aeb1cf64cff18758204a89f5f17f694b8` 的历史服务生成，全部为
合成数据。文件记录历史源码哈希并由加载器固定完整文件摘要；CI 不依赖旧 Git 对象或
旧 Python 模块，后来的运行时修改不会悄悄重写历史期望值。

历史测试装配只做两项明确修正：账面零数量仍会产生一条隐式零实盘行，故断言从零行
修正为一行；物料 UUID 作为原始请求显式输入，使回填能够无损证明原请求身份。
历史服务和数据库守卫源码未改。最终样本保留一个未注册 SN 的待核实观察、一个隐式
零实盘行、原始哈希、授权快照、状态事件、审计和 outbox。

0051 的 0022 任务 UPDATE 触发器有已知时间戳分支错误。沿用原历史造数的唯一例外：
